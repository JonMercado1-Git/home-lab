# home-lab

Documenting my networking, virtualization, and security projects — for learning and portfolio.

## Structure
- `00-lab-log/` — running log of what I did, when, and how long
- `01-virtualization/` — hypervisors, VMs
- `02-networking/` — topologies, VLANs, routing, firewall
- `03-services/` — self-hosted services, Docker
- `04-security/` — SIEM, hardening, detection
- `diagrams/` — network diagrams (draw.io / Mermaid)
- `templates/` — reusable project + log templates

## Environment
- **Windows 11 PC** — main virtualization host (2 monitors)
- **HP laptop** — Omarchy Linux (services, Pi-hole, etc.)
